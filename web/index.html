Questions

Who is Regulift for?

Lifters who outgrew static programs — the 5/3/1s and spreadsheets — and want the programming to react to what the log says.

Does it work with Apple Watch?

Yes. Log sets from the wrist, and the rest timer runs as a Live Activity.

What does it read from Apple Health?

Read-only sleep, heart-rate variability and resting heart rate to sharpen the readiness score. Granting access is optional — check-ins alone work.

Does it work offline?

Training, logging and the program math run on-device. Only the coach chat needs a connection.

Can I cancel?

Any time, in your App Store account settings. Access continues to the end of the paid period.
