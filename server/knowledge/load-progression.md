# Load progression

## Load progression: auto-regulation

Per exercise, compare actual vs target RPE and set Δ = RPE_actual − RPE_target. If Δ ≤ −1.0 (too easy): load_next = load × 1.05, add 5%. If Δ = −0.5: load_next = load × 1.025. If Δ = 0: keep load (× 1.0) and add reps next session (double progression). If Δ = +0.5: repeat the same load. If Δ ≥ +1.0: load_next = load × 0.95, reduce 5% and flag fatigue.

## Load progression: double progression

For isolation and dumbbell work, use a target rep range (e.g. 8–12). Hit the top of the range on all sets at RPE ≤ target → increase load by the smallest increment (2.5 lb / 1 kg). At the new load, restart at the bottom of the range.
