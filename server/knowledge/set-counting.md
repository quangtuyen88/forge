# Set counting

## Set counting: RIR cutoff

A set counts toward a muscle's volume only if taken within 0–4 RIR (reps in reserve). Sets taken further from failure do not count as hard sets.

## Set counting: compounds

Compound exercises count 1:1 for the primary mover and 0.5 for synergists. Example: bench press = 1 chest + 0.5 triceps + 0.5 front delt.

## Set counting: isolation

Isolation exercises count 1:1 toward the target muscle's volume.
